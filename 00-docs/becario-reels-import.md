# becario-reels import

Source, license and port notes for the "becario-reels" pack. The pack was ported into the Video Studio engine
as the reels template family (category `reels-2d`).

Icons: the pack uses Lucide (ISC, via `lucide-react`). The port does not add that dependency. It draws Phosphor
duotone icons (MIT), which the engine already ships, and `lib/reels.mjs` (`ICON_ALIASES`) maps common Lucide names to
Phosphor. An unknown name falls back to the four-point spark, and the build logs it.

## What was ported

| Pack | Engine |
|---|---|
| 17 scene types (`src/escenas`, `src/piezas`) | `src/reels/escenas/`, `src/reels/piezas/`. The components are kept almost verbatim. Canonical ids are English (`headline`, `counter`, `stats`, `card`, `list`, `steps`, `compare`, `strike`, `objection`, `quiz`, `bars`, `image`, `gallery`, `phone`, `chat`, `editor`, `cta`). The pack's Spanish names work as `tipo`, and scene fields keep the pack's names. |
| Moments `en` (`motor/linea.ts`) | `lib/reels.mjs`: `parseMoment`, `resolveMoment`, `distributeMoments`, `wordFrame`. Supports `"word"`, `"word#2"`, `"word+6"` / `"word-4"`, `"inicio"` / `"fin"` and frame numbers. Words appear 4 frames early. Moments missing from `en` are spread over the scene. Word times come from the engine's TTS + whisper captions, aligned to the script. |
| 5 series styles with role colors (`motor/estilos.ts`) | `REEL_STYLES` in `lib/reels.mjs`, one template per style (`templates/reels-{nube,noche,menta,limon,pizarra}.json`). `reelColors()` maps a `theme.palette` override onto the roles (background, cards, panels, lines, text, accent + readable accent text). |
| Transitions `corte` / `suave` / `semitono`, per-sentence `entrada` | `src/reels/motor/Escena.tsx`. Cut 1 frame before the first word; soft scenes overlap 10 frames. |
| Subtitles `linea` / `bloque`, keywords from `*asterisks*` | `src/reels/motor/Subtitulos.tsx`. Resized to stay inside the 900x1300 safe box. The voice never reads the asterisks. |
| Scene sounds | The pack's WAVs play on scene moments (`src/reels/ReelsVideo.tsx`), scaled by `sfx.volume`. Extra sounds: `reel.sfx`. |
| `ritmo.py` (">0.6 s without visual change") | `02-scripts/rhythm-check.mjs`. Same method (3 screen zones + 90x80 tiles, 540x960 gray), using `05-tools/bin/ffmpeg`. Exits 1 on gaps. |
| Portada + `PortadaCheck` (3:4 profile-grid crop) | `src/reels/Cover.tsx`. The build writes `cover.jpg` and `cover-check.png`. `node cli.mjs cover <spec> --out <dir>` renders only those. |
| Contact sheet (`render.mjs fotos`) | `node lib/reels-stills.mjs <spec> <out> --sheet` writes `sheet.png`: the middle, each moment and the end of every scene. |

Not ported:
- The mascot/character with poses (`personaje.md`, `poses.py`): no mascot unless asked.
- Custom scenes (`propias`).
- The pack's own voice/alignment scripts (`voz.py`, `alinear.py`). The engine's Kokoro/ElevenLabs + whisper pipeline replaces them.
- Brand font overrides per style. Only colors are overridable, through `theme.palette`.

## Use

```bash
source ./env.sh   # from the repo root
cd 07-studio/engine
node cli.mjs validate examples/reels-noche.spec.json
node cli.mjs build examples/reels-noche.spec.json --out <outDir>   # video.mp4, cover.jpg, cover-check.png, post.md
node lib/reels-stills.mjs examples/reels-catalog.spec.json <outDir> --template=reels-limon --sheet --cover
node ../../02-scripts/rhythm-check.mjs <outDir>/video.mp4
```

Spec shape: `visual: {"type": "reel", "reel": {"type": "counter", "valor": 50, "en": ["ahorras", "mes"]}}`. The
narration is the sentence, with `*keywords*`. Optional top-level `reels: {subtitles, transition, cover}`. The scene
vocabulary and limits are in each template's `prompt_hint` and in `prompts/spec-writer.md` ("Reels templates").
