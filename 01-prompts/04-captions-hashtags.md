# Captions + hashtags per platform
```
Write platform-native captions for this video.

Video summary: {summary}
Keywords people would search: {keywords}
CTA: {cta}
Language: {language}

Produce three blocks:
1. TikTok: first line ≤ 80 chars that reinforces the hook (searchable keyword in it), 1–3 short lines, CTA, 3–5 hashtags (mix 1 broad, 2 niche, 1 branded).
2. Instagram Reels: first 125 chars carry the hook + keyword (shown before "more"), 3–6 short lines of value/context, CTA asking for a send or save, MAX 5 hashtags.
3. YouTube Shorts: Title ≤ 60 chars (key phrase in first 40), description 2–3 lines with keywords, 3 hashtags (these display above the title).
Also give 3 alt titles/first lines for A/B testing. No emojis unless {emoji_policy}.
```
