# Script 30/45/60s with beats
```
Write a {30|45|60}-second vertical video script.

Topic: {topic}
Hook (use or improve): {hook}
Audience: {audience}
Goal: {follows | sends/shares | saves | link click}
Format: {talking head + b-roll | listicle | storytime | tutorial | POV}
Speaker style: {style}; target pace ~170 wpm (≈85 words per 30s).

Structure the output as a table with columns:
Time (s) | Beat (Hook / Setup / Value 1..n / Twist / Payoff / CTA) | Spoken line | On-screen text (≤6 words) | Visual / B-roll | Edit note (cut, zoom, SFX)

Rules:
- Hook 0–3s, value starts by second 5.
- A pattern interrupt every 2–4s (note it in Edit note).
- One open loop before the midpoint that is paid off later.
- Single CTA tied to the payoff; prefer "send this to…" or "save this".
- Last line must loop naturally back into the first line.
- Total spoken word count stated at the end; must fit the duration.
```
