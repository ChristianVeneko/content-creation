# /video — guided short-video creation

You are the producer and the spec writer: the user's Claude Code subscription is the LLM, nothing calls the Anthropic/OpenAI/Gemini APIs. Talk in the user's language (Spanish by default), short messages, few clear questions, smart defaults, a visible plan, then a finished video.

Run everything from the repo root (the folder that holds `env.sh`); every shell command starts with `source ./env.sh &&`. Never install globally or into `~`. Shorthands (set them in each command): `J=.claude/skills/canal/jobs.mjs`, `H=.claude/skills/hooks`.

**Token budget.** Read only what a step names. Never read whole: `07-studio/engine/README.md`, `00-docs/template-styles.md`, `07-studio/engine/prompts/spec-writer.md`, full `templates` JSON. Use the lean commands and section extracts below. Platform rules are in Rules at the end; do not reread the playbook.

## 0. Channel and context

1. `node $J channels`. Use a channel only if the user named it in this request. Otherwise ALWAYS ask, even with a single channel: `AskUserQuestion` (header "Canal"): "Sin canal (Recomendado)" first, then one option per channel. Never infer the channel from the topic or from earlier videos. None exist → continue without a channel (mention `/canal` in one line).
   Without a channel: no `brand` (no handle, no avatar watermark), no channel defaults, `node $J new` without `--channel`. `brand.handle`/`brand.avatar` come only from the chosen channel's `channel.json`.
2. With a channel, read only `08-channels/<slug>/channel.json` and `voice.md`. Its `defaults` pre-answer onboarding (format/template, palette, voice, captions, music, duration, tone); `language`, `audience` and `voice.md` steer the script; never break a "no afirmo" or banned word.
3. Formats: `node 07-studio/engine/cli.mjs templates --brief` (id, category, format, name, best for). Category `hyperframes` = the animated HyperFrames formats (pixel-world "Pixel animado", flat-2d "2D animado"): they are data-driven, so new ones appear here on their own; they are handled by §2b. EXCEPTION: when the user wants pixel / pixel art / "Pixel animado", do NOT use the pixel-world engine: load the `pixel` skill (`.claude/skills/pixel/SKILL.md`), which has the agent draw the video by hand (it also requires the `/hooks` flow, the title/cover lint and a payoff closing line: do them, never skip them), and follow it instead of §2b-§4 for that video. Metaphors: use the real subject drawn literally; at most one metaphor per video, only when it clarifies (user: "no me gusta el abuso de las metáforas"). If the command fails, say so in one line and offer §5.

## 1. Capture the idea

Take the topic from the message; if none, ask "¿De qué trata el video?" and wait. Detect given inputs (file path, URL, project folder, script). An existing idea (`/video <id>` or a title listed by `node $J status <slug>` with stage `idea`) → reuse that folder; its `notes` hold the promise. Do not re-ask anything known.

## 1b. Research: facts before the script (videos from scratch)

A video made from scratch (the user gave a topic, not a script, footage or a finished text) is built on facts you checked today. Skip this step only when the user gave the full script, or the video states no facts (a pure opinion, a joke, a fiction they wrote).
1. Search with `WebSearch` (2-4 queries in Spanish and English: the topic, "datos", "historia", "cifras", the year) and open the best 3-6 pages with `WebFetch`. Prefer primary and official sources (agencies, universities, papers, the company or league itself, court records), then established press and reference works. Never cite a page you did not open.
2. Keep a fact only when an opened page states it; a figure, date or name that carries the hook needs two independent sites. Sources that disagree, rumors and "se dice" go to "Fuera del video", never into the narration.
3. Write the table to `$P/sources.md` (template `04-projects/_template/sources.md`; until the project exists in §3.1, keep it in the conversation): one row per fact with where it is used, the URL and today's read date. Then `node 02-scripts/sources-check.mjs $P/sources.md`; fix every FAIL before writing the script.
4. Use the research to choose the angle: the most surprising verified fact is the hook candidate for §3.2, and the payoff line closes on a verified consequence. Tell the user in one line how many facts you verified and what you left out.
5. Kits with their own facts step (`science-shorts`, `moment-reel`) write the same table in their folder: link it from `$P/brief.md` and run the same check on it. Sources go only in the YouTube description (`post.md`), never in narration or on screen.

## 2. Onboarding: format first (AskUserQuestion, max 3 rounds)

Group up to 4 questions per call (AskUserQuestion allows at most 4 options per question); skip any answered, irrelevant, or fixed by the channel defaults (say in one line which defaults apply: "Uso los ajustes de <canal>: reels-noche, voz ElevenLabs en tendencia, 1 min"). Recommended first, marked "(Recomendado)", and each default explained in one short line. "tú decide" / "lo que veas" → take every default and continue. Order of decisions: the idea (§1), then what it looks like and how it moves (format, scene mode), then style and setting/colors, then voice, tone, captions and music, then length. An optional Round 4 ("Ajustes avanzados") exists for HyperFrames formats only.

**Round 1: route, format and length**
1. Tipo (skip unless the request is ambiguous): "Plantilla rápida (Recomendado)" (engine) / "Motion graphics a medida" (HyperFrames) / "Animación en código estilo Opus" (`05-tools/repos/awesome-opus5-5-videos/prompts/`) / "Estilo de cine en código" (`opuscar`: 66 looks, acuarela, tiza, satélite, despiece, anime 80s, cine mudo…; catálogo `00-docs/opuscar-styles.md`) / "Lanzamiento de un proyecto" (`/brag`). Kinetic classics (`captions-voice`, `kinetic-type`, `countdown`, `glass-cards`, `letterbox`) only if the user types one.
   - Two kit formats live outside `templates --brief`; add them as options when the idea fits (they are handled by §5, ask nothing else about formats): "Ciencia animada" (`science-shorts`: flat-vector science explainer with objects that have faces, chunky labels that pop on their word and a title card, 45-80 s; fits a surprising science fact, "cuánto pesa / qué tan grande / por qué") and "Patio en corte 3D" (`whatif-3d`: a house and lawn above soil cut open like a cake, a thing is built step by step "si cavas un hoyo… pero… así que…", 60-75 s or more; fits how an everyday system works underground or in the yard) and "Momento famoso en caricatura" (`moment-reel`: a famous moment (a goal, a launch, a trial, a discovery) told as a flat 2D cartoon with thick outlines and expressive faces, the act first, then the chain that led to it, the context and the consequence, freezes on the key instant, 2-4 word captions, 30-50 s; fits "cómo pasó X", a famous play, a historic mistake) and "Historia de supervivencia 3D" (`story-video`: second-person thriller "Imagina que…" with a clock HUD, 3-4 rules on stickers, low-poly three.js sets with flat 2D stickmen, a twist and a two-choice ending for the comments, 60-75 s; fits a tech horror story: an agent loose in production, a poisoned package, a malicious repo).
   - Say once, when a 3D format is in play: "Las plantillas 3D solo fijan el estilo (cámara, luz, materiales, movimiento): yo construyo los modelos desde cero y pruebo varias tomas de cámara por escena." Pixel adds a `character` only if asked.
   - Motor de render (solo plantillas 3D): "Remotion / three.js (Recomendado)" (rápido, ~2 min) / "Blender Eevee" (más cinematográfico, sombras y materiales suaves, ~0,3 s/frame). Si eligen Blender, escribe `theme.renderer: "blender"`; Remotion es el valor por omisión y queda omitido. Para videos 2D con HyperFrames en vez de Remotion, usa la ruta §5 con `hyperframes-brief`.
   - Modo de escenas (HyperFrames formats only; each format lists its `modes` in `template <id>`): "Una escena continua" (`mode: "single"`: one world, one camera travelling between stations, no cuts; Recomendado for process, step by step, before/after, novice vs pro duel) / "Varias escenas" (`mode: "multi"`: a sequence of worlds joined by cuts or wipes; Recomendado for story, ranking, one world per idea). Mark the recommended one from the topic and explain it in one line.
3. Plataforma: "Las 3 (Recomendado)" / Reels / TikTok / Shorts (skip if the channel lists platforms).
4. Duración: "30 s (Recomendado)" / "1 min" / "2 min" / "Otra" (typed: 15 s, 45 s, 1,5 min, 2,5 min or 3 min). Allowed totals: 15, 30, 45, 60, 90, 120, 150, 180 s (max 3 min).
